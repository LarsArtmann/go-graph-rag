  lint load failure ×1 (this session).

  the tag/CHANGELOG. Nothing fails if a release forgets it.

  the start (now encoded in AGENTS.md Commands).
- Include `go mod verify` in the release command set.
- Word CHANGELOG intros precisely: "no exported signature changed" was
  ambiguous next to an Added section that adds an exported field — it means
